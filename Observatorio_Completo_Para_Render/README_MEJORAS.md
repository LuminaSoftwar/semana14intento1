# Mejoras del Dashboard PC12

- Filtros territoriales en cascada: departamento, provincia y distrito.
- Selección independiente del año de análisis y del año de comparación (no se permite comparar un año consigo mismo).
- La variación porcentual compara el total anual del ámbito territorial elegido entre ambos años.
- Se conservan los cuatro KPI mínimos solicitados y se añaden dos KPI complementarios: robos y hurtos.
- El gráfico circular usa las mismas cantidades de robos, hurtos, extorsión y homicidios que muestran sus KPI; la categoría "Otros delitos" completa el total.
- Títulos y secciones del Dashboard con jerarquía visual reforzada.
- Todos los valores estadísticos siguen siendo simulados y se identifican como tales.
