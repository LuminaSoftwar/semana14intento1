# Prueba exploratoria con usuarios

Invitar a tres voluntarios ajenos al equipo. Explicar el propósito y pedir autorización antes de registrar tiempos y observaciones. No recopilar nombres, DNI, audio ni datos sensibles; usar códigos U01–U03. Cada voluntario realiza las mismas dos tareas.

**Instrucción al participante:** “Explora el Observatorio como lo harías normalmente. No hay respuestas correctas o incorrectas. Puedes detenerte cuando quieras. Tomaremos tiempo y anotaremos dificultades, sin registrar datos que te identifiquen.”

## Tareas

- **T01:** Encuentra la página de consulta, selecciona un indicador y consulta un periodo.
- **T02:** Filtra por una localidad disponible, interpreta el resultado y descarga el CSV si está habilitado.
